# Team context

Everything in this folder is loaded on demand by skills and referenced from
AGENTS.md. Keep files short and anonymised (no client names, no customer data).

- `team.md` who the team is, which repositories hold tickets, review habits.
- `design-principles.md` the principles every design is checked against.
- `glossary.md` team vocabulary so briefs and tickets use the same words.
- `component-library.md` how to look components up and naming rules.
